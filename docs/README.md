# Documentación de TriajeVN

Bienvenido a la documentación de `TriajeVN`, una prueba de concepto de un sistema de triaje de incidencias para soporte técnico.

## Contenido

- `introduccion.md` - descripción general del proyecto y su alcance.
- `instalacion.md` - requisitos y pasos para instalar y ejecutar el proyecto en local.
- `arquitectura.md` - explicación de la arquitectura del sistema y sus componentes.
- `api.md` - definición de los endpoints REST disponibles.
- `uso.md` - guía de uso de la aplicación web y ejemplos prácticos.

## Cómo usar esta carpeta

Abra los archivos anteriores para encontrar información específica sobre la instalación, la arquitectura, la API y el uso del proyecto.
